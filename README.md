# Shark Tank Investment Analysis

## Project Overview

This project analyzes startup investment trends using Shark Tank data. 
The analysis focuses on industry-wise investment, deal success, top-funded startups, 
Shark participation, and the relationship between asking amount and deal amount.

## Objectives

- Analyze startup investment trends
- Compare investment across industries
- Analyze deal success rates
- Identify top startups by investment
- Analyze Shark participation
- Study the relationship between asking amount and actual deal amount

## Tools Used

- Python
- Pandas
- Matplotlib
- Tableau
- Excel

## Dataset

The dataset contains startup information including:

- Brand Name
- Industry
- Deal
- Deal Amount
- Pitcher Ask Amount
- Shark participation

## Analysis Performed

### Python & Matplotlib

- Data cleaning
- Industry-wise investment analysis
- Industry-wise deal analysis
- Deal vs No Deal analysis
- Average investment analysis
- Data visualization

### Tableau

The Tableau dashboard contains:

- Total Investment
- Total Startups
- Deal Success Rate
- Industry Investment
- Deal vs No Deal
- Top 10 Startups
- Shark Deals
- Ask Amount vs Deal Amount

## Key Findings

- Total Startups: **117**
- Startups Receiving Deals: **65**
- Deal Success Rate: **55.6%**
- Piyush Deals: **27**
- Namita Deals: **22**
- Ghazal Deals: **7**

The Ask Amount vs Deal Amount scatter plot shows a generally positive relationship,
suggesting that startups asking for higher amounts tend to receive higher deal amounts.
